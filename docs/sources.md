# Sources

The source registry, with tier, type and reliability, is shown publicly on `/sources` and described on the Methodology page. The collector configuration (33 feeds, 5 listings: 3 gov.pl pages, the Latvian armed forces news list and Sargs.lv and GDELT queries, full-text opt-ins, and domains never read because of their terms or because they block automated access) is `data/sources/collector.json`.

## Live statements

For a statement seen live, such as a head of state speaking on television, before any registry source reports it, attach the reserved source "Live statement (broadcast)" to the event (migration 0013). Type who said it and where you saw it, for example "President Trump — live remarks, White House (seen on Fox News)", and put their words in the excerpt. A link is optional. That name is shown in place of the outlet, and pages show "Live broadcast — no link yet" until a link is added. The source is Tier 1 official, so it can support publishing on its own. Use it only when the event reports the speaker's own words, and attach the registry source once outlets publish the story (decision 22). Events only: exercises and the historical record cannot cite it, and the source cannot be deleted.
